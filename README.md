# 🌐 Main Project Highlight

<div align="center">

## ResilientNet

### Offline Delay-Tolerant Mesh Messenger for Android

</div>

**ResilientNet** is an offline-first Android communication system designed to keep people connected when internet access is weak, blocked, unstable, or completely unavailable.

It focuses on:

* 📡 Offline device-to-device communication
* 🔗 Mesh-style message forwarding
* 📲 Android communication without internet
* 🧠 Delivery confidence and routing logic
* 🛡️ Communication resilience during emergencies
* 🌍 Real-world use cases in crisis zones, events, rural areas, and low-connectivity environments

This project shows my passion for **networking, mobile development, decentralized systems, and solving real communication problems**.
